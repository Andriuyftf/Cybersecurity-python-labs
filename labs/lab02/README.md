Варіант 13 — Сканер витоків конфіденційних даних (PII Exfiltration Scanner).



Структура файлів

Модулі лабораторної роботи знаходяться в `labs/lab02/`:

| Файл або каталог      | Призначення |
|                       |                                       |
| `__init__.py`         | Позначає каталог як пакет Python.     |
| `main.py`             | Запускає команди `demo` та `analyze`. |
| `task1.py`            | Містить класи першого завдання.       |
| `task2.py`            | Містить сканер конфіденційних даних.  |
| `README.md`           | Містить інструкцію запуску.           |
| `data/`               | Містить вхідні файли.                 |


Приклади запуску

Демонстрація першого завдання:

python -m labs.lab02.main demo


Команда показує невдалий та успішний вхід, перевірку email, керування правами
адміністратора, завершення сеансу за таймаутом, вихід і журнал аудиту.
Для демонстрації таймауту час останньої активності зміщується в минуле,
тому чекати 15 хвилин не потрібно.

Пошук усіх типів даних із маскуванням консольного виводу:

python -m labs.lab02.main analyze --scan-dir labs/lab02/data/data_v13/scan --patterns all --mask --out-json labs/lab02/pii_scan_summary.json


Пошук лише номерів карток:

python -m labs.lab02.main analyze --scan-dir labs/lab02/data/data_v13/scan --patterns cards --mask --out-json labs/lab02/cards_report.json


Пошук лише email:

python -m labs.lab02.main analyze --scan-dir labs/lab02/data/data_v13/scan --patterns emails --mask --out-json labs/lab02/emails_report.json



Параметри CLI

Команда `demo` не приймає додаткових аргументів. Команда `analyze` підтримує:

| Параметр     | Обов'язковість | Призначення                                                                    |
|              |                |                                                                                |
| `--scan-dir` | Обов'язковий   | Шлях до каталога для рекурсивного сканування.                                  |
| `--patterns` | Необов'язковий | `all` — усі типи, `cards` — картки, `emails` — email. Типове значення: `all`.  |
| `--mask`     | Необов'язковий | Маскує знайдені значення у консолі. Без прапорця значення виводяться відкрито. |
| `--out-json` | Обов'язковий   | Шлях до підсумкового JSON-звіту.                                               |

JSON-звіт завжди містить масковані значення, незалежно від `--mask`.
У консолі показуються перші 10 знахідок, а у JSON записуються всі знахідки.
Звіт містить каталог сканування, режим пошуку, кількість оброблених і пропущених
файлів, лічильники типів та список знахідок із шляхом, номером рядка, типом і значенням.
Батьківський каталог звіту створюється автоматично. Наявний файл звіту перезаписується;
поточний файл `--out-json` виключається зі сканування.

Кожен збіг підраховується окремо, включно з повторними. Для чотирьох навчальних
файлів варіанта 13 у режимі `all` результат становить 4 email, 3 номери карток,
4 телефони та 4 IPv4-адреси — разом 15 збігів.
